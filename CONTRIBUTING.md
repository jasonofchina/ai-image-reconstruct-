# 贡献指南 / Contribution Guide

感谢你对 AI 图像智能重构项目的关注与支持！我们欢迎来自社区的反馈、改进建议及代码贡献。

## 🤝 我们欢迎的贡献类型 / We Welcome

- 提出 Bug 反馈（通过 Issues）
- 提交功能建议（通过 Issues 或 Discussions）
- 优化文档（如 README、示例、指引等）
- 提交代码（Pull Request）
- 完善测试用例

## 📌 如何贡献 / How to Contribute

### 1. 提出问题（Issue）
如你遇到问题、有改进建议或疑问：
1. 前往 [Issues](https://github.com/jasonofchina/ai-image-reconstruct-/issues) 页面
2. 选择合适的模板（Bug 反馈 或 功能建议）
3. 清晰描述问题、复现步骤与期望结果

### 2. 提交代码（Pull Request）
如你想直接改进代码或文档：
1. Fork 本仓库
2. 创建你的分支：`git checkout -b feature/your-feature`
3. 提交你的修改：`git commit -m '描述你的修改'`
4. 推送至你的分支：`git push origin feature/your-feature`
5. 在 GitHub 提交 Pull Request

## 🛠️ 开发规范 / Guidelines

- 所有功能需附带对应测试用例（可放入 examples/）
- 修改 skill.md 时请同步更新 README 中的使用说明
- 保持代码和文档清晰易读
- 遵循已有的代码风格与目录结构

## 🙏 致谢 / Thanks

感谢每一份贡献，让我们一起打造更强大、更可靠的 AI 图像重构工具！

# Contribution Guide

Thank you for your interest in the AI Image Intelligent Reconstruction project. We welcome community feedback, suggestions, and code contributions.

## 🤝 Types of Contributions

- Bug reports (via Issues)
- Feature requests (via Issues or Discussions)
- Documentation improvements (e.g. README, examples)
- Code contributions (Pull Requests)
- Test case enhancements

## 📌 How to Contribute

### 1. Report Issues
- Go to [Issues](https://github.com/jasonofchina/ai-image-reconstruct-/issues)
- Use the Bug Report or Feature Request template
- Clearly describe the issue, steps to reproduce, and expected result

### 2. Submit Code
- Fork the repo
- Create a branch: `git checkout -b feature/your-feature`
- Commit changes: `git commit -m 'your message'`
- Push: `git push origin feature/your-feature`
- Open a Pull Request

## 🛠️ Guidelines

- Include test cases for new features (put in examples/)
- Update README if modifying skill.md
- Keep code/docs clean and readable
- Follow existing style and structure

## 🙏 Thanks

Together, let's make this a more powerful and reliable tool!
